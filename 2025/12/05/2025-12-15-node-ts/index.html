A.修改package.json
添加"type": "module"，这告诉Node.js这个项目是ESM项目。

B.修改tsconfig.json
推荐的 tsconfig.json 关键配置项示例：

  • "target": "es2020" 或更高 (设置编译目标 JavaScript 版本)
  • "module": "commonjs" 或 "module": "NodeNext" (设置模块系统)
  • "outDir": "./dist" (设置编译后文件的输出目录，如果您需要编译)
  • "rootDir": "./src" (设置 TypeScript 文件的根目录)
  • "esModuleInterop": true (更好地处理 CommonJS 和 ES Modules 的导入/导出)
  • "strict": true (开启所有严格类型检查，推荐)
  • "include": ["src/**/*"]定义哪些目录和文件应该被编译器包含
